# SC2002 Restaurant Rush

Java command-line restaurant management game for the SC2002 group assignment.

The [assignment brief](SC2002_Restaurant_Rush_Group_Assignment.docx.pdf) is the source of truth for the game rules and submission requirements.

The [component contract](docs/component-contract.md) records the team's agreed rules, responsibilities, turn timing, and implementation decisions. Its shared Java API section remains to be specified before parallel implementation issues are assigned.

## Project status

The repository currently contains the assignment brief and project setup. The game has not been implemented yet.

## Planned stages

| Tag | Required milestone |
| --- | --- |
| `stage-1` | Complete base game with Regular customers and both outcomes |
| `stage-2` | Add VIP and Critic customer behavior |
| `stage-3` | Add Host, ComboMeal, and Happy Hour |

Each tag will identify a tested, runnable commit. Build and run instructions, stage change summaries, reproducible run notes, and video timestamps will be added as the corresponding work is completed.

## Team workflow

Track a coherent piece of work in each GitHub issue using the work-item form. Work on a branch, open a pull request using the repository template and link it to the issue, review and merge it, then tag the tested milestone commit when a stage is complete. Specify the shared Java API in the contract before assigning dependent implementation work.
